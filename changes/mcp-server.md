## Connect an agent to the sea with MCP

Claude Code, Cursor and any agent that speaks the Model Context Protocol can now read Tonnr directly: what the buoys and the wind stations measure, the forecast of waves and wind at a point, the tides, and the catalogue of surf breaks. Give your agent the address of the API followed by `/mcp` and an API key, and ask it how the surf looks: it finds the spot, reads the forecast, the tide and what surfers wrote of the place, and says where the data comes from. Whoever runs an instance sees in the admin how much agents call, and whose.
